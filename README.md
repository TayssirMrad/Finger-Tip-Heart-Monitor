# Finger-Tip-Heart-Monitor
This is a project that uses an Arduino Nano microcontroller to measure heart rate and blood oxygen saturation from a finger using a MAX30102 sensor. The data is displayed on an SSD1306 OLED screen. The circuit also includes three pushbuttons with pull-up resistors and debouncing capacitors for user input.

###Features
- Measures heart rate and blood oxygen saturation (SpO₂).
- Displays real-time data on an OLED screen.
